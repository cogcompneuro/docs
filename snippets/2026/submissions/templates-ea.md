Extended Abstract submissions must use one of the **LaTeX** (at least v2026.1),
**Word** (at least v2026.2), or **Typst** (at least v2026.3) templates, all available
in the
[CCN template repository](https://github.com/cogcompneuro/ccn-template)
([download zip](https://github.com/cogcompneuro/ccn-template/archive/refs/heads/main.zip)).
Follow the repository README for setup instructions.
