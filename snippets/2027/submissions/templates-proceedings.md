Proceedings submissions use the **LaTeX** (at least v2026.1) or **Typst** (at least
v2026.3) template, both available in the
[CCN template repository](https://github.com/cogcompneuro/ccn-template)
([download zip](https://github.com/cogcompneuro/ccn-template/archive/refs/heads/main.zip)).
Follow the repository README for setup instructions. The Word template is not accepted
for the Proceedings track.
